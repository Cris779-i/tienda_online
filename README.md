# API de Tienda Online

Proyecto desarrollado para el curso Backend con Python y Django (INACAP).
Permite buscar productos por nombre en una tienda online simulada, mostrando
una página de resultado si el producto existe, o una página personalizada
de "recurso no encontrado" si no existe o si la URL no es válida.

## Requisitos

- Python 3.x
